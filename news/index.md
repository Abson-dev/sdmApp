# Changelog

## sdmApp 0.0.3

### Breaking and infrastructure changes

- Dropped the archived `rgdal` and `rgeos` dependencies. `sdmApp` now
  relies on `raster` (\>= 3.6.3), which reaches GDAL, GEOS and PROJ
  through `terra`, so the package installs again on current R.
- Reworked `DESCRIPTION`: packages actually used by the exported
  functions moved to `Imports`; the modelling engines used only inside
  the shiny interface stay in `Suggests` and are checked at launch.
- `NAMESPACE` is now generated by roxygen2 from targeted `@importFrom`
  tags instead of a blanket `exportPattern()` and long `@import` lists.

### Fixes

- [`sdmApp()`](https://abson-dev.github.io/sdmApp/reference/sdmApp.md)
  no longer calls itself recursively and builds the shiny app only once.
  It validates `theme` and `maxRequestSize` up front and stops with an
  informative message listing any missing suggested packages.
- Replaced the deprecated
  [`ggplot2::aes_string()`](https://ggplot2.tidyverse.org/reference/aes_.html)
  with `aes()` and `.data[[ ]]` across the mapping helpers.
- Replaced `guides(fill = FALSE)` with `guides(fill = "none")`.
- Replaced fragile `class(x) == "SpatialBlock"` comparisons with
  [`inherits()`](https://rdrr.io/r/base/class.html).
- Added input validation to
  [`sdmApp_PA()`](https://abson-dev.github.io/sdmApp/reference/sdmApp_PA.md),
  [`sdmApp_RasterPlot()`](https://abson-dev.github.io/sdmApp/reference/sdmApp_RasterPlot.md),
  [`sdmApp_TimesRasters()`](https://abson-dev.github.io/sdmApp/reference/sdmApp_TimesRasters.md)
  and
  [`sdmApp_fold_Explorer()`](https://abson-dev.github.io/sdmApp/reference/sdmApp_fold_Explorer.md).

### Testing and CI

- Replaced the placeholder unit tests with real tests that exercise the
  exported functions against the bundled example data.
- Rebuilt the GitHub Actions workflows (`R-CMD-check`, `pkgdown`,
  `test-coverage`, `lint`) on `r-lib/actions` v2 and current runners.
